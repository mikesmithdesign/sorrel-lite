# Sorrel Lite: free one-page template for hair salons & barbershops

A single-file HTML template with editorial type over a clay-warm palette,
arch-shaped photography, a booking form and a live open/closed badge. No
build step, no frameworks. Open `index.html` and edit.

**Live demo:** https://sorrel-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html`: salon name, services, hours,
   contact details.
2. Replace the photos in `img/` with your own (keep the filenames, or
   update the `src` paths).
3. Set your opening hours in the `HOURS` table near the top of `site.js`
   (day 0 = Sunday; `[9, 18]` = 9am–6pm; `null` = closed).
4. Upload anywhere. It's static files. Vercel, Netlify and GitHub Pages
   host it free.
